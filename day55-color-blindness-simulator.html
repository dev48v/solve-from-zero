Roughly 1 in 12 men can't tell your red from your green.

Human colour vision runs on three kinds of cone — L (long / red-ish), M (medium / green-ish) and S (short / blue-ish). Every colour you see is really just those three numbers. In the most common colour-vision deficiencies one cone type is missing, so a whole dimension of colour collapses: reds and greens fold onto the same murky yellows. This tool simulates that from scratch. It converts each pixel out of gamma-encoded sRGB into linear light, multiplies by a 3×3 matrix to get the LMS cone responses, projects those onto the plane a dichromat can still tell apart, then converts back to sRGB to display — the standard Viénot/Brettel LMS transform, applied by hand on canvas ImageData with no library. Load a built-in scene or drop your own image (read locally with FileReader, never sent anywhere), and use the contrast-collapse checker to see which colour pairs survive each deficiency. This is not the Day-18 WCAG contrast tool — that measures luminance ratios; this simulates colour vision itself.

Five things worth knowing about colour-vision deficiency

1. It is almost never "black and white". Total colour blindness (achromatopsia) is vanishingly rare — about 1 in 33,000. The common forms are dichromacies: you still see colour, just with one axis missing, so reds and greens both read as yellows. 2. Red-green is X-linked, which is why it is mostly men. The L and M cone genes sit on the X chromosome; men have one X, so a single faulty copy shows, while women usually have a spare — hence ~8% of men versus ~0.5% of women. 3. You must linearise first. sRGB values are gamma-encoded; averaging or matrix-multiplying them directly gives wrong colours. The transform only makes sense in linear light, so we undo gamma, do the cone math, then re-apply it. 4. The simulation is a projection. Removing a cone collapses 3-D colour onto a 2-D plane — the plane of colours a dichromat can still tell apart — which is exactly why two very different originals can map to the identical simulated colour. 5. Never encode meaning in colour alone. The contrast-collapse checker shows red/green status dots merging under deuteranopia; that is why good UI adds an icon, a label or a shape, not just a hue.

🔨 Build it yourself

    
A colour-blindness simulator is really just a chain of small, exact steps applied to every pixel: undo the sRGB gamma to get linear light, multiply by a 3×3 matrix to reach the three cone responses (LMS), multiply again by a projection matrix that models the missing cone, then run the two conversions in reverse to get a displayable colour. The only libraries in play are Uint8ClampedArray and the 2-D canvas you already have. Achromatopsia is even simpler — collapse to luminance. Here it is, step by step.

    
    
      
  1. 
        
    1
    Two colour spaces: sRGB and linear
    
        
    The 0–255 values in an image are gamma-encoded sRGB — perceptually spaced, not proportional to light. All the cone math must happen in linear light, so we need to undo the gamma going in and re-apply it coming out. A 256-entry lookup table makes the forward direction free.
    
        
    function srgbToLinear(c){           // 0..255 -> 0..1 linear
  c /= 255;
  return c <= 0.04045 ? c / 12.92
                      : Math.pow((c + 0.055) / 1.055, 2.4);
}
function linearToSrgb(c){           // 0..1 linear -> 0..255
  const v = c <= 0.0031308 ? c * 12.92
                           : 1.055 * Math.pow(c, 1 / 2.4) - 0.055;
  return Math.max(0, Math.min(255, Math.round(v * 255)));
}
const S2L = new Float64Array(256);            // fast forward LUT
for (let i = 0; i < 256; i++) S2L[i] = srgbToLinear(i);
    
      
    2. 
      
  2. 
        
    2
    Linear RGB → LMS cone responses
    
        
    A 3×3 matrix maps linear R, G, B to how strongly each cone type fires: L (long / reddish), M (medium / greenish), S (short / bluish). This is the space colour vision actually lives in, and the space where a missing cone is a clean, removable dimension.
    
        
    const RGB_TO_LMS = [
  [0.31399022, 0.63951294, 0.04649755],   // L
  [0.15537241, 0.75789446, 0.08670142],   // M
  [0.01775239, 0.10944209, 0.87256922],   // S
];
    
      
    3. 
      
  3. 
        
    3
    The dichromat projection matrices
    
        
    Each deficiency is a matrix that rebuilds the missing cone's signal from the two that remain — projecting 3-D colour onto the plane the dichromat can still separate. Protanopia has no L cone, deuteranopia no M, tritanopia no S. (Normal vision is the identity matrix, so it returns the pixel unchanged.)
    
        
    const SIM = {
  normal:       [[1,0,0], [0,1,0], [0,0,1]],
  protanopia:   [[0, 1.05118294, -0.05116099], [0,1,0], [0,0,1]],
  deuteranopia: [[1,0,0], [0.9513092, 0, 0.04866992], [0,0,1]],
  tritanopia:   [[1,0,0], [0,1,0], [-0.86744736, 1.86727089, 0]],
};
    
      
    4. 
      
  4. 
        
    4
    LMS → back to linear RGB
    
        
    To display the simulated colour we invert step 2: the inverse matrix takes the projected LMS back to linear RGB, which step 1's linearToSrgb then turns into a paintable 0–255 value.
    
        
    const LMS_TO_RGB = [
  [ 5.47221206, -4.64196010,  0.16963708],
  [-1.12524190,  2.29317094, -0.16789520],
  [ 0.02980165, -0.19318073,  1.16364789],
];
const dot = (row, x, y, z) => row[0]*x + row[1]*y + row[2]*z;
    
      
    5. 
      
  5. 
        
    5
    One pixel, end to end
    
        
    Chain it together: linearise, project to LMS, apply the deficiency matrix, come back to RGB, re-gamma. Normal vision short-circuits to an exact copy so the "original" panel is bit-for-bit identical.
    
        
    function simRGB(r, g, b, type){
  if (type === "normal") return [r, g, b];                 // identity
  const lr = S2L[r], lg = S2L[g], lb = S2L[b];             // 1. linear
  const M = RGB_TO_LMS;
  const L = dot(M[0], lr, lg, lb),
        Q = dot(M[1], lr, lg, lb),
        S = dot(M[2], lr, lg, lb);                          // 2. LMS
  const P = SIM[type];
  const L2 = dot(P[0], L, Q, S),
        Q2 = dot(P[1], L, Q, S),
        S2 = dot(P[2], L, Q, S);                            // 3. project
  const N = LMS_TO_RGB;
  return [                                                  // 4. + 5.
    linearToSrgb(dot(N[0], L2, Q2, S2)),
    linearToSrgb(dot(N[1], L2, Q2, S2)),
    linearToSrgb(dot(N[2], L2, Q2, S2)),
  ];
}
    
      
    6. 
      
  6. 
        
    6
    Achromatopsia = luminance only
    
        
    Total colour blindness needs no cone matrix — there is no colour left, only brightness. Compute the Rec.709 linear luminance and paint it into all three channels. Weighting in linear light (not on the raw bytes) is what keeps the greys perceptually right.
    
        
    function achromatopsia(r, g, b){
  const y = 0.2126*S2L[r] + 0.7152*S2L[g] + 0.0722*S2L[b]; // luminance
  const v = linearToSrgb(y);
  return [v, v, v];                                         // grey
}
    
      
    7. 
      
  7. 
        
    7
    Run it over a whole image
    
        
    Pull the pixels out of the canvas with getImageData, walk the flat Uint8ClampedArray four bytes at a time (R,G,B,A), simulate each pixel, and write into a fresh output buffer — alpha copied straight through. Then putImageData onto the target canvas.
    
        
    function simulateInto(src, dst, type){
  for (let i = 0; i < src.length; i += 4){
    const [r, g, b] = type === "achromatopsia"
      ? achromatopsia(src[i], src[i+1], src[i+2])
      : simRGB(src[i], src[i+1], src[i+2], type);
    dst[i] = r; dst[i+1] = g; dst[i+2] = b;
    dst[i+3] = src[i+3];                        // keep alpha
  }
}

    8
    Load an image — with no upload
    
        
    FileReader.readAsDataURL turns the dropped file into a data: URI entirely in the browser — nothing is sent to a server. Draw the decoded image onto the source canvas (scaled to a sane width) and re-run every simulation.
    
        
    function loadFile(file){
  const reader = new FileReader();             // local only, no network
  reader.onload = () => {
    const img = new Image();
    img.onload = () => { drawToSource(img); renderAll(); };
    img.src = reader.result;                    // the data: URI
  };
  reader.readAsDataURL(file);
}

  9. 
        
    9
    Contrast collapse — do two colours survive?
    
        
    Simulate both colours under a deficiency, convert each to CIE-Lab, and take the CIE76 ΔE distance between them. A large ΔE means they stay distinct; a tiny ΔE means the deficiency has merged them. This is what turns "red/green is bad" into a number.
    
        
    function collapse(rgbA, rgbB, type){
  const a = type === "achromatopsia" ? achromatopsia(...rgbA) : simRGB(...rgbA, type);
  const b = type === "achromatopsia" ? achromatopsia(...rgbB) : simRGB(...rgbB, type);
  return deltaE(labOf(a), labOf(b));           // CIE76 distance
}
// ΔE < 5 -> collapses · 5..15 -> risky · > 15 -> distinct

  10. 
        
    10
    Prove it: pure red, and the identity
    
        
    Two checks pin the math down. Normal vision must return the input untouched. And pure red, run through deuteranopia, must shift toward a dark yellow — because a green-blind eye rebuilds the missing M signal and red slides onto the yellow axis. If red still looks pure red, the matrices are wrong.
    
        
    console.assert(
  simRGB(200, 50, 90, "normal").join() === "200,50,90",
  "normal vision is the identity");                              // ✓

const red = simRGB(255, 0, 0, "deuteranopia");   // -> ~[156,156,0]
console.assert(red[1] > 100 && red[2] < 40,
  "pure red collapses toward yellow for a green-blind eye");     // ✓
